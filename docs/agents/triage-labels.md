# Triage labels

| Status | Use when |
| --- | --- |
| `needs-triage` | A maintainer needs to review the request. |
| `needs-info` | A decision or missing detail is needed to finish specifying the work. |
| `ready-for-agent` | The work is specified and an agent can implement it. |
| `ready-for-human` | The work requires a human to carry it out. |
| `wontfix` | The maintainer has decided to close the request without implementing it. |
