# One-step setup and the combined Codex picker

A developer connects from one API-key field. New Desktop and CLI chats use a single combined provider. Ordinary models retain native billing and labels. Each eligible Route model has a stable `route-` alias and the display name **Route 6.2 Sol**, **Route 6.2 Astra**, or the matching family and version. Selecting a different row retains the chat, workspace and tool results. The default preference selects one of the visible rows.

The first gate requires stock clients, separate credentials, observed upstream requests, and portable conversation history through switching, compaction and resume. Use disposable profiles before touching installer or activation code. Existing chats retain their provider. Keep the legacy Route provider for its existing chats. Disconnect restores journaled settings conditionally and invalidates the local token. Reconnect issues a new token. Forget also deletes the saved key.

A coordinated release requires both clients on macOS, Windows and graphical Debian 13, client-generated images on a rendered page, and at most 50 ms p95 added time to the first complete stream event. Record fixture, live and graphical observations separately.
