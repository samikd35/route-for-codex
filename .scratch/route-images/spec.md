# Generate images in Codex with a project key

A developer who connects Route with an OpenAI API project key can ask either stock Codex client to generate an illustration and use it on a local page. A fresh, signed-out profile must support the entire task. Setup registers the Route image tool in the shared Codex configuration. The relay uses the saved key for both the coding model and the Images API. [Architecture](../../ARCHITECTURE.md) · [Qualification record](../../docs/api-key-only-images.md)
